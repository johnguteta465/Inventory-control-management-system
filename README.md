# Inventory Management System


## Overview

A modern desktop application built with **C# Windows Forms, SQL Server, and ADO.NET** for managing inventory, sales, and reporting in small to medium businesses.

It helps automate and simplify:

-  Inventory tracking  
-  Sales management  
-  Reporting & analytics  

## Features

###  Authentication & Authorization
- User login & registration  
- Role-based access (Admin / Staff)  
- Secure session handling  

###  Product Management
- Add, edit, delete products  
- Category & supplier management  
- Search and filter products  
- Real-time stock tracking  

###  Stock Management
- Stock In (Purchases)  
- Stock Out (Sales)  
- Automatic stock updates  
- Prevent selling unavailable stock  

###  Reporting & Analytics
- Sales reports (date filter)  
- Stock reports  
- Low stock alerts  
- Dashboard with charts  
- Export to CSV / Excel  

### 📷 Advanced Features
- Barcode scanner support  
- Barcode printing  
- Desktop notifications  
- Database backup (.bak)  

###  Admin Panel
- User management  
- Role assignment  
- Backup & restore system  



##  Technologies Used

- C# (.NET Windows Forms)  
- SQL Server  
- ADO.NET  
- Visual Studio
